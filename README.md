
# FoodieGo – Food Ordering and Delivery Management System

## Project Overview
FoodieGo is a proposed food ordering and delivery management system designed to make online food ordering simple, convenient, and user-friendly.

The system aims to allow customers to explore food items, add products to a shopping cart, place orders, and manage their food ordering experience.

This repository contains the front-end prototype and project management resources developed as part of a Software Project Management (SPM) academic project.

## Project Objectives
- Provide a simple and user-friendly food ordering interface.
- Display food items with their names, descriptions, and prices.
- Allow users to search and filter food items.
- Enable users to add food items to a shopping cart.
- Calculate the total order amount automatically.
- Demonstrate the basic order placement process.

## Main Features
- Homepage and navigation menu.
- Food menu with different food categories.
- Food search functionality.
- Category-based filtering.
- Add to Cart functionality.
- Increase and decrease item quantities.
- Automatic cart total calculation.
- Order confirmation message.

## How to Run the Prototype
1. Download or clone this repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Double-click `index.html` to open it in a web browser.
5. Explore the food menu and test the available features.

## Prototype Limitations
This version is a front-end academic prototype. It demonstrates the basic user interface and food ordering interactions.

The following features are not yet implemented:
- Real user registration and authentication.
- Backend server and database connectivity.
- Real online payment processing.
- Live delivery tracking.
- Actual restaurant and delivery service integration.

## Project Scope
The proposed FoodieGo system focuses on food browsing, ordering, cart management, and delivery-related functionality. The current prototype demonstrates selected front-end features, while advanced system functionality remains part of the proposed future development.
